# フォルダー構成

| 場所 | 役割 |
| --- | --- |
| cli/ | 実行コマンド |
| src/ | 組版・検品・保存などの共通処理 |
| templates/ | 読書画面の雛形 |
| scripts/ | PythonのPDF書き出し |
| tests/ | 回帰検証と検証用データの作成 |
| docs/ | 現行の制作手順・設計資料 |
| docs/history/ | 旧版の説明・改訂記録 |
| works/ | 作品ごとの原作・設定・素材・制作途中・完成出力 |
| releases/ | 確定済みの再現パッケージ |
| .manga-history/ | 途中状態の保存・復元 |

新しいコマンドは `node cli/auto.mjs` のように実行します。ルート直下の同名ファイルは旧コマンド・importの互換入口です。実装の変更は cli/・src/・tests/ 内で行ってください。

MANGA_PROJECTは引き続きリポジトリルートからの相対パスです。コードの置き場所や呼び出し元の作業フォルダーを作品ルートとして扱いません。従来どおり作品を明示して使います。

保存・復元と再現パッケージには、互換入口に加えcli/・src/・scripts/・templates/・tests/の実体も含めます。以前のロックはコード移動後に不一致となります。元のreleases/や履歴から復元した当時の一式を使って再現し、既存ロックのハッシュを書き換えて通過させないでください。新構成での改訂版は必要な再確認・再現検証後に別パッケージとして保存します。

既存の作品・素材・履歴・旧版出力は移動していません。旧版のローカルデータ整理は参照関係を確認したうえで別途行います。
