# フォルダー構成

| 場所 | 役割 |
| --- | --- |
| cli/ | 実行コマンド |
| src/ | 組版・検品・保存などの共通処理 |
| templates/ | 読書画面の雛形 |
| scripts/ | PythonのPDF書き出し |
| tests/ | 回帰検証と検証用データの作成 |
| docs/ | 現行の制作手順・設計資料 |
| docs/history/ | 旧版の説明・改訂記録 |
| works/ | 作品ごとの原作・設定・素材・制作途中・完成出力 |
| releases/ | 確定済みの再現パッケージ |
| .manga-history/ | 途中状態の保存・復元 |

コマンドは `node cli/auto.mjs` のように実行します。共通処理は src/ からimportし、検証は tests/ を使います。ルート直下の旧コマンド・import用ファイルは廃止しました。外部スクリプトも新しいパスへ更新してください。

`cli/workflow.mjs` の文字・図形計算と処理は、次の共通モジュールに分けています。

| モジュール | 役割 |
| --- | --- |
| `src/lettering.mjs` | 文字列の列分割、吹き出し寸法、尾・衝突判定、文字と吹き出しのSVG |
| `src/dialogue-layout.mjs` | 入力を変更せず配置候補を返す探索 |
| `src/story-state.mjs` | 衣装・小道具の設定継承と制作入力の検査 |
| `src/generation-jobs.mjs` | 生成指示・参照・fingerprintの組み立て |
| `src/assets.mjs` | PNG検査、候補照合、素材採用、履歴保存 |
| `src/project.mjs` | `loadProject()` による作品設定の明示的な読み込みと履歴登録 |

引数解析、ページ合成、工程を進めるコマンド分岐、配置結果の保存はCLI側にあります。共通モジュールをimportするだけでは作品設定の読み込みや履歴保存を開始しません。作品を扱うCLIは `loadProject()` を呼びます。`local()` は従来どおりリポジトリ内の相対パスを検査します。

`node tests/verify-refactor.mjs` は、分割前のコードから保存した92件のハッシュと、ページ・コマ方式それぞれの旧・新プロンプトによるSVG・HTML・ジョブ・配置探索結果を照合します。`tests/fixtures/workflow-refactor.json` は検証用の白いPNGと人工脚本の期待値です。実作品の素材・検品記録や再現ロックとは別のもので、検査を通すために現在の出力から更新しません。

MANGA_PROJECTは引き続きリポジトリルートからの相対パスです。コードの置き場所や呼び出し元の作業フォルダーを作品ルートとして扱いません。従来どおり作品を明示して使います。

保存・復元と再現パッケージには、cli/・src/・scripts/・templates/・tests/の実体を含めます。以前のロックはコード移動後に不一致となります。元のreleases/や履歴から復元した当時の一式を使って再現し、既存ロックのハッシュを書き換えて通過させないでください。新構成での改訂版は必要な再確認・再現検証後に別パッケージとして保存します。

既存の作品・素材・履歴・旧版出力は移動していません。旧版のローカルデータ整理は参照関係を確認したうえで別途行います。
