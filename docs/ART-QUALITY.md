# 第7版：描画の不自然さを減らす工程

「AIっぽさが完全に消えた」「人が描いた絵になった」と保証する機能ではない。新規AI生成は非決定的で、見る人によって絵柄の評価も異なる。目立つ構造の破綻を見つけ、採用を止め、修正して再確認するための工程を実装した。

## 資料の扱い

ユーザー提供の「AI生成画像の『AI生成っぽさ』を減らす技術の実証的研究レポート」を参考にした。一次資料として [Kamaliほか：Characterizing Photorealism and Artifacts in Diffusion Model-Generated Images](https://arxiv.org/abs/2502.11989) を確認した。この研究は写真と生成写真の識別・アーティファクトの分析であり、白黒漫画での改善効果を直接測った研究ではない。接触、人体、物体の整合性や選別を漫画に応用するのは制作上の判断で、研究の識別率を本ツールの効果として転用していない。

漫画では、指の数だけでなく親指の側、手首からのつながり、物を持つ接触、指輪を付ける指、隠れた部分の前後関係を見る。顔では目線と表情、髪では束のまとまりを確認する。寄りの背景を省略し、人物の外形と内部線の強弱を分ける。ノイズや紙の質感で破綻を覆う処理は追加していない。提供資料のSD/ComfyUI向けCFG・denoise値は、内蔵画像生成ツールの設定として使えないため実装していない。

## 共通の仕組み

- 新規作品は version: 7 と quality.required: true。作品固有の人物・衣装・舞台は従来どおり各作品に保存する。
- quality.drawing と quality.avoid を生成指示へ反映。原作の小道具や自然な表情を維持し、線の整理と余白を優先する。
- quality-plan が合成ページと各コマの検品画面、記録雛形を作る。縮小、100%、200%を切り替えられる。
- anatomy / contact / objects / faces / linework / background / continuity / lettering の8項目に、pass / fail / na と観察理由を記録する。na は見えていない対象だけに使う。背景のないコマは、その省略が意図に合うかを background に記録する。
- fail または未解決の問題があれば、build と layers を拒否する。未記録、未確認の表示倍率、古い記録も拒否する。
- 記録は素材、切り出し範囲、コマの位置・台詞・人物情報、生成計画と描画方針に紐付く。絵や座標を変更したら、再確認する。
- quality-repair が問題の記録からコマ単位の修正指示と参照素材を保存する。画像生成ツールへの依頼自体はCodexが行い、自動で料金のかかるAPIを実行しない。
- 既存の話者・顔・読順・連続性のページ確認も必要。描画検品だけで吹き出しの確認を代替しない。

検品結果は目視の記録である。CLIはJSONの形式と失効を確認できるが、指や表情を画像認識して採点する機能ではない。記録に実際の観察を書かず、すべてに機械的にpassを付けると工程の意味がなくなる。

## 修正の順序

### 手の左右とレビュー判断の確認

画面の上下だけで親指の正誤を決めない。まず見えている面が掌か手の甲か、指がどちらを向いているか、母指の基部がどちら側かを記録し、肩→肘→前腕→手首→手の経路と合わせる。母指先端の動き、隠れた指、白い袖の重なりから所有者を推測した場合は、その限界も書く。[右手の掌面図](https://www.anatomyatlases.org/atlasofanatomy/plate12/05volarrh.shtml)と[右手の背面図](https://www.anatomyatlases.org/atlasofanatomy/plate05/12rhanddorsal.shtml)は、観察面を区別する照合資料として使える。これらは人体確認用の資料で、本編の絵柄参照や転載素材にはしない。

レビュー担当の左右判断が食い違ったら、生成を進める前に別担当が元図と対象を実見し、観察面・回転・腕の経路を照合する。図を見ずに記憶した左右規則だけで修正要求を出さない。誤りが画像ではなくレビュー判断にあった場合も、旧回答を消さず、新しい回答へ訂正根拠を保存して正式に再記録する。「レビュー判断の訂正」と「画像を編集して修正」を区別する。同じコマを3回修正しても不備が残る場合は、[自動制作手順](AUTOMATIC.md)に従って問題と全試行を保存し、そのコマの修正を停止する。未採用素材を検品済みとして完成出力へ入れない。

1. 複数候補を生成し、原作の意図、構図、人体、接触の読みやすさで比較する。
2. 構造の破綻は、手と触れている小道具など相互に関係する対象をまとめて修正する。
3. 構造を維持して、髪・服・背景の不要な細線と陰影を整理する。
4. 修正後の素材を目視し、顔・口・保護範囲を測り直して採用する。
5. 合成ページと全項目を再確認する。AIで直せない場合は手作業の修正を選べるが、実施していない手描き工程を実施済みと記録しない。

今回の新規画像修正は結婚指輪の手元のコマ。左右が曖昧な最初の候補を見送り、両方の左手と薬指の指輪が判別できる構図へ変更した。細かい皮膚陰影を整理した後、合成確認で見つかった袖口と腕まくりの食い違いも、不合格記録から修正した。既存の他の素材は新しい方針で生成し直した画像ではない。線の密度や絵柄の好みについては、引き続き編集判断が必要である。

## 検証の限界

白いPNGを使う回帰テストは、検品の必須化、不合格・未解決問題の拒否、修正指示、素材変更時の失効、完成出力の保持を検証する。実際の漫画の魅力や自然さを保証するテストではない。AI利用の由来や採用履歴を保存し、検出器の回避や由来の偽装は目的にしない。

第7版のパッケージは保存容量の制約から圧縮形式も用意した。過去の確定版と素材は削除しない。圧縮内の全ファイルのSHA-256を照合し、採用素材からのSVG・HTMLの同一再構築を確認する。
