# v0.1.0 — Initial public release

This release pins the first tested version of Manga Generator for readers who want to try adapting a UTF-8 story with Codex. The repository includes the CLI, workflow documentation, and a [finished two-panel sample page](https://github.com/stockedge/manga-generator/blob/v0.1.0/docs/showcase/novel-account-page-01.png). The sample demonstrates the output format; its full source story and production assets are not included in this Git repository.

## What's included

- Story intake and resumable project state; script, storyboard, panel, quality, and independent-review gates.
- Separate lettering and page composition, browser reader, PDF workflow, retained candidates/history, and reproducibility packaging from saved adopted artwork.
- Japanese and English getting-started guides, plus the public sample page and social preview.

## Verified environment and checks

- Windows PowerShell, Node.js `v24.18.0`, npm `11.16.0` (24 October 2026).
- `$env:MANGA_PROJECT='works/kensei/workflow.json'; npm run check` — passed. This includes workflow validation and synthetic-fixture regression checks; it does not verify the visual quality of generated artwork.
- `npm run check:code` — ESLint, Prettier, and TypeScript checks passed.
- The committed two-panel sample was visually inspected for panel layout and readable lettering.

## Known limits

- Automatic production needs an available image-generation tool, actual image inspection, independent subagent reviews, and sufficient tool quota and disk space. The CLI intake command alone does not make a finished manga.
- Image generation is nondeterministic. Saved adopted artwork can be recomposed reproducibly; a new generation cannot be guaranteed to match it.
- The production works and complete source for the sample are not distributed with this repository. A local legacy `kensei` work did not pass `tests/verify-workflow.mjs` because its `storyboard/01` subagent review is missing under the current gate. This release does not claim that legacy work is rebuilt or certified by this version.
- The full PDF and image-generation workflow was not independently rerun for this release; the passing tests use synthetic fixtures for those paths.
