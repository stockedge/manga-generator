# Manga Generator v0.3.1

公開日：2026年11月16日。通常制作の脚本・ネーム設計へ、文字量・コマ割り・人数・ショットを確認する参考集計と警告を追加しました。

- 自動制作の指示へ、原作の意味・動作・応答を優先する統計の参考ガイドを追加。
- 予定ショット`cameraCrop`を生成指示と脚本レビューへ反映。古い指定の生成ジョブを使う準備操作を拒否。
- `speakers: null`でも監査が停止せず、人物情報を未登録として扱うよう修正。

利用手順は[統計を参考にした脚本・ネーム設計](../MANGA-STATISTICS.md)、出典・未確認事項・独自ルールは[参考資料と設計判断](../RELEASE-SOURCES.md)を参照してください。統計への近さを品質点や合否基準には使いません。

検証：回帰テスト・コードチェックとマージ後のGitHub CIが成功。探索資料・実験画像・ログはリリースに含めていません。
