# Manga Generator v0.3.0

Released 2026-11-16. This release adds optional production assistance and
strengthens the checks connecting scripts, artwork, reviews, and exports.

References and implementation boundaries: [参考資料と設計判断](../RELEASE-SOURCES.md).

## Optional production assistance

- The [assistance CLI](../ASSIST.md) creates production indexes, intake drafts,
  character cards, spread previews, and offline delivery plans. It does not
  publish or adopt artwork automatically.
- Bounded pixel edits, mask inspection, format conversion, layout candidates,
  and ordinary RGB8 pixel-layer PSD exchange can run from the CLI. Pillow is
  required for image helpers; PSD exchange additionally requires psd-tools.
- External edits can be connected to their original generation evidence with
  `generation record-edit`. Input/output hashes, edit instructions, and parent
  records are checked without claiming a new AI generation.
- Optional horizontal sound effects are composed separately from artwork,
  with checks against faces, protected areas, dialogue, and balloon tails.

## Planning, review, and source fidelity

- Composition audits report aspect-ratio whitespace, face size, and page
  density for visual review.
- Optional storyboard images and sketches support planning; explicit crops
  support reuse of existing panel artwork. Planning guides stay out of final
  artwork, and changed storyboard images invalidate generation identity.
- First-reading and staged-review checks better preserve source meaning,
  reading order, and current rendered inputs.
- Kakuyomu imports retain ruby readings as `base《reading》`.
- Added the [Indonesian README](../../README.id.md) and corrected its setup
  repository URL.

## Export and reproduction safeguards

- PNG render receipts bind saved images to their SVG inputs. Delivery drafts
  additionally require ready pages and SVGs matching the current script and
  materials.
- Portable bundles retain render receipts and generation-log references,
  including explicitly referenced research images. Unrelated research remains
  excluded from distribution freezes.
- Crop replacement checks allow a valid larger candidate while preserving
  invalid-candidate rejection. Incompatible page fallback is rejected before
  an accepted panel override is removed.
- Pixel and cumulative PSD-layer limits reject oversized allocations before
  decoding or resizing. Input hashes describe the bytes actually processed.

## Documentation and validation

- Added the Indonesian README and corrected its repository URL.
- Updated production guides and their self-contained Agent Skill copies.
- Regression coverage includes edited-generation provenance, stale delivery
  inputs, bundle retention, crop replacement, image budgets, and changing
  inputs. Pillow-only environments skip the optional PSD subset and continue
  the remaining image checks.
- Release checks cover Node lint, formatting, types and regression tests;
  Markdown and bundled-skill validation; and Python lint, formatting and tests.

## Known limits

- Image and layout helpers produce candidates that still require inspection,
  formal adoption, coordinate measurements, and the applicable reviews.
- PSD exchange is limited to supported pixel layers; editable text and full
  compatibility with external drawing applications are not guaranteed.
- Automated checks and synthetic fixtures do not certify artwork quality or
  story quality. New AI image generation is nondeterministic; reproduction
  rebuilds layout from saved adopted assets.
