# Manga Generator v0.2.0

Public release of the manga production environment with multilingual guides,
continuous checks, and Agent Skills. This release was cut from `master` and
released 2026-11-01.

## Multilingual guides

- [README translations](../..) in eight locales plus Japanese, with consistent
  commands, links, and workflow references across all nine files.
- [Production economy mode](../PRODUCTION-MODES.md) with isolated incremental
  reviews, compressed history generations, and managed temporary caches.
- Redesigned [social preview](../showcase/social-preview-gpt-prompt.md) and
  recorded [day-seven adoption metrics](../GITHUB-ADOPTION.md).

## Continuous checks

- [CI](../..) runs three jobs on every push and pull request: Markdown lint,
  Node checks (`check:code` plus the full `check` suite against
  `works/sample`), and Python checks (`ruff check`, `ruff format --check`,
  unit test).
- The Node job provisions headless Chrome for the export screenshot tests and
  pins every action to a commit SHA with least-privilege permissions.
- Reader builds are deterministic across checkouts: the reader template is
  normalized to LF so CRLF and LF checkouts produce identical `reader.html`.

## Agent Skills

- [Skills](../../.agents/skills/manga-production/SKILL.md) for production,
  [review](../../.agents/skills/manga-review/SKILL.md), and
  [art direction](../../.agents/skills/manga-art-direction/SKILL.md), each
  self-contained with its referenced docs bundled under `references/`.
- `tests/verify-skills.mjs` validates skill frontmatter, in-skill link
  resolution, and copy-to-source sync; CI runs it in the Markdown job.
- Install into another project with `npx skills add stockedge/manga-generator`.

## Verified checks

- CI `markdown`, `node`, and `python` jobs pass on the tagged commit.
- `muse skills validate` passes for all three skills with zero diagnostics.
- `npx skills` discovers and installs the skills with bundled references.
- `npm run check` passes in full against `works/sample`.

## Known limits

- The `works/sample` project and white-PNG fixtures are synthetic stand-ins,
  not finished artwork. New AI image generation itself is nondeterministic;
  what reproduces from saved materials is the layout from adopted assets.
- Skill auto-triggering varies by agent product; use explicit requests such as
  "review this page with manga-review" when the skill does not engage.
