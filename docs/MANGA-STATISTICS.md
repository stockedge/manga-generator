# 統計を参考にした脚本・ネーム設計

通常制作では、原作の意味・問いと返答・動作・時系列を先に固定し、その後に以下の目安を使う。作画前の `production-audit work` の `statistics` と警告を読み、偏りが場面に必要か検討する。変更後も同じ監査を行い、番号なしネームを実読する。比率を合わせるためだけの台詞削除、無言コマの水増し、人数やショットの変更は禁止する。

## 参照値と使い方

参照はユーザー提供のManga109-s統計画像3枚（2026年11月16日）。原データと集計定義の全体は未取得であり、同じデータセットを再集計したものではない。

| 指標 | 画像の参照値 | ネームでの扱い |
| --- | --- | --- |
| 無言 | 全コマの20.2% | 動作・反応・余韻を絵で示せるか検討。ノルマにはしない |
| 台詞ありの文字数 | 中央値21字、90%点50字、95%点62字 | 説明が続く場合は意味単位の分割や絵への置換を検討。上限ではない |
| コマ数 | 見開き中央値10コマ | 通常場面では1ページ5コマ前後を初期案の目安にする。ページごとの狙いを優先 |
| 面積 | 見開き比中央値5.6% | 片ページ比では約11.2%。見せ場の大ゴマや見開きを通常コマと区別 |
| 人数 | 0人15.0%、1人43.9%、2人30.7%、3人以上10.4% | 会話を毎回2ショットにせず、話者・反応の寄り、物や背景も必要に応じて選ぶ |
| 単独人物のショット | 推定可能な1人コマで肩40.7%、バスト30.2%、腰12.5%、膝8.7%、全身7.8% | 感情を伝える寄りと、位置・動作を伝える引きを使い分ける。全コマの分布ではない |

平均や中央値からテンプレートを一種類に固定しない。原作の長い発話、無言中心の場面、群衆、見開きなどは、その役割を説明して保持できる。

## 集計定義と不足

- 文字数は台詞と地の文のUnicodeコードポイント数。空白・改行を除き、句読点を含める。擬音は含めない。画像の集計定義と完全一致すると主張しない。
- 面積比は `panel.rect` の面積を片ページ面積の2倍で割る。片ページ自体を見開きと取り違えない。物理的な見開きのペアや変形コマの実面積は推定しない。
- 人数は `speakers` に登録された可視人物数。地の文と画面外の声を除き、後頭部は含める。未登録人物・群衆を画像から認識した値ではない。空の登録と実際の無人コマも区別して画像で確認する。
- `panel.cameraCrop` は単独人物の計画上の切れ位置を `shoulder` / `bust` / `waist` / `knee` / `full` で記録する。手元・物だけのコマには付けない。自由記述の `camera` や顔枠比率から自動推定しない。未記録はunknownとし、分母を表示する。作画後は実画像と再照合する。
- `cameraCrop` は生成指示と脚本レビューに含まれる。変更した場合は通常の再plan・採用・再レビューを行う。統計監査そのものは脚本や画像を書き換えない。

## 警告の意味

100字超が1コマに集中、50字超が3コマ以上連続、単独人物の同じ明示ショットが3コマ以上連続、4ページ以上がすべて同じコマ数、12コマ以上がすべて文字あり、12コマ以上で半数超が縦横比2.6超の場合に検討を促す。これらの連続数は本ツールの暫定的な監査ルールで、統計資料から得た閾値でも有意差でもない。

警告だけで生成・完成を拒否せず、統計への近さを品質点に変換しない。自然な読順、原作の意味、実寸の文字・顔・動作の見やすさは従来どおり実見と独立レビューで確認する。完成済み作品は統計を理由に再生成しない。
